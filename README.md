# 抽签转盘

在线使用：https://yirochi08-arch.github.io/lucky-wheel/

单个 `index.html`，不依赖任何外部资源；名单、设置、记录只存在自己的浏览器里。底部四个入口：转盘 / 上上签 / 名单 / 设置。

## 转盘

- 圣诞红绿黄半圆转盘，波浪扇区、彩灯、卡通小手指针。
- 两种转法：**指针摆动**（小手来回摆）或 **转盘旋转**（小手在顶上不动，转盘转圈，划过每格会被拨一下）。
- 动效：入场扇区展开、小手摆入；转动时彩灯追光、小手残影、当前扇区高亮、标题实时滚动名字、滴答声；落定时中奖扇区弹出描边、其余变淡、彩灯齐闪、名字落定、彩带和星星、结果卡片弹出。

## 上上签

红色签筒，点「摇一摇 · 求签」：签筒摇晃、签子跳动，一支签升起，展开成大签显示结果。和转盘共用同一份名单和规则。

## 名单组 + 先选「我是谁」

- 名单可以存多组，例如「圣诞交换礼物」「今天吃点啥？」，随时切换；每项可停用、改名、删除，支持批量编辑和按数字生成。
- 打开「抽之前先选我是谁」后：每个人先在名单里选中自己再抽，**不会抽到自己**；抽完卡片上点「我记住了，下一位」，结果会隐藏、并自动弹出下一位的选择。
- 配合「抽中后：移出」就是交换礼物玩法：每人抽一次、每人只被抽中一次，并且不会让最后一个人只剩自己可抽。

## 分享链接

- 转盘页、上上签页右上角，或名单页的「分享这个抽签」：每个名单组单独生成一条链接，选对方看到转盘还是上上签、是否每人只能抽一次。
- 收到链接的人只看到这一个抽签页面：没有底部标签栏、设置、名单编辑和切换形式。
- 整个抽签编码在链接的 `#` 后面，不经过服务器；每台手机自己记住抽没抽过、抽到了什么。
- 「先选我是谁 + 抽中后移出」的名单组在生成链接时就随机配好对（没人抽到自己、不会两人抽到同一个），所以大家各自用手机抽也不会撞。名单改了会生成新链接，旧链接还是旧名单。
- 局限：没有服务器，发起人看不到谁已经抽了；链接里的配对只是编码、不是加密，懂技术的人能解出来。

## 头像

名单页点任意一项的头像，可以换成 emoji（48 个常用的，或自己输入）；「你是谁」、名单、结果卡片和分享链接里都会用这个头像。

## 设置

- **抽签规则**（每个名单组各自一套）：每次抽几个、抽中后放回/移出/置灰、概率人人相同/按权重/洗牌轮转、指针停在随机位置或正中。结果用 `crypto.getRandomValues` 事先决定，转盘和签筒只负责演出来。
- **转盘**：转动方式、时长、圈数、四种停下方式。
- **效果**：转盘文字、圣诞彩灯、彩带、音效、结果卡片。
- **抽签记录**：所有名单组的历史，含「谁 → 抽到谁」。
